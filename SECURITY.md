# Security Policy

## Supported versions

This repository contains the source of the document decoder and schema. Security fixes are made on the `main` branch. Git snapshots and forks are not supported releases.

## Report a vulnerability

Report suspected vulnerabilities privately to [hello@textmode.art](mailto:hello@textmode.art). Do not open a public issue, pull request, discussion, or Discord thread for a security report.

Include the affected commit or package version, runtime, a minimal reproduction, and the expected security impact. Do not include secrets or private user documents unless the maintainers request a secure method to share them.

The maintainers will make a best effort to acknowledge reports within five business days, investigate the issue, and coordinate a fix and disclosure.

## Scope

This policy covers the decoder, schema, and documentation maintained in this repository. It does not cover vulnerabilities in applications that consume the package or third-party services and dependencies outside this repository's control.
